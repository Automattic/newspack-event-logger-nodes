The salt rotation IS the schema migration, and nothing compensates for skipping it

Flushing is the substrate's one button. Rotating the salt moves the install scope that prefixes every memcache key of every Newspack plugin at once, so a schema change orphans the old keys the instant the salt moves. The durable mirror is the one tier the button does not reach, and it carries the one version component this decision otherwise rejects.

Memcache: the scope moves, and the old keys are unreachable

Before: a stats key, as the substrate's Table writes it through Cache_Backend::site_key().

newspack_nodes:{v}:a1b2c3d4e5f6:table:evlog:p0:hourly:2026-09-11-14-05

The scope is the first 12 hex of md5( DB_NAME : table prefix : salt ). Stats_Store keeps no salt of its own.

wp nodes memcache flush→Cache_Backend::rotate_salt() stores a new salt

After: the same logical key under a new scope. The old key still sits in memcache until its TTL, and nothing will ever ask for it.

newspack_nodes:{v}:9f8e7d6c5b4a:table:evlog:p0:hourly:2026-09-11-14-05

A long-running worker memoizes the scope for its life: restart workers for immediate effect.

The durable mirror: no scope, its own version

The mirror exists to outlive the flush (decision 10), so its key carries no install scope and the rotation reaches nothing on disk.

evlog:m1:p0:{key}

Stats_Store::entry_key(). The m1 is MIRROR_KEY_VERSION, folded into every durable key.

a frame shape changes→bump MIRROR_KEY_VERSION
evlog:m2:p0:{key}

The mirror's own migration lever. Nothing compensates for skipping that bump either.

Skip the button

The dashboard reads garbage for one retention window. That is an operator error with a one-command fix, wp nodes memcache flush, not a case for the runtime to detect.

No second mechanism beside it

No reader or writer carries a shape probe, a version component in a memcache key, or a row-level legacy test. Each would be a second migration mechanism beside this one button, maintained against every future row shape.

One mechanism, two uses

Schema bumps and emergency flushes share it: a flush and a migration are the same rotation.
