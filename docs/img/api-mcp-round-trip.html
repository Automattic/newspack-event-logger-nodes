One POST carries every MCP method, and the session's scope is a ceiling

Six hops take a tool call from an agent to the same verb handler the dashboards drive, and its reply back as one JSON-RPC response. The gate decides whose authority is spent; the interpreter behind it is the one /command reaches.

Agent

An MCP client registered once with the handle and key a command session issued.

The gate

MCP_Controller::check_permission(), the route's permission callback.

JSON-RPC

MCP_Controller::dispatch(): one route, POST …/newspack-event-logger-nodes/v1/mcp, four methods.

The verb

The performance or rules interpreter, mounted by Bootstrap::mount_request_graph(), and its handler.

4The call becomes a command
A name absent from the ten tools, OR a role the session cannot spend: -32601 Unknown tool: <name>. A typo and a permission refusal get one answer; tools/list is what tells them apart.
The named arguments become a flat token list: every key in POSITIONAL_ARGS (descriptor, hash, rid, pattern, rule, id, context) rides bare, in that order; every other key becomes --key=value through Command_Args::format().
$node->dispatch( verb, tokens ) on the CI the tool names. The verb's own capability gate and handler run exactly as they do for /command; the MCP layer adds no verb.
5A return value becomes one text content block: the string as it is, anything else JSON-encoded. A throw becomes result.isError: true with the message as the text: a tool error, not a transport error, because the call reached the server and was answered.
6{ jsonrpc: "2.0", id, result } or { jsonrpc: "2.0", id, error: { code, message } }. Nothing in a reply asks the agent to act; wiring a client up is the operator's deliberate act.

What a session sees: the ceiling only subtracts

A tool is offered and callable only when the session's scope covers its role AND the minting user holds that capability. A manage-scoped session minted by a user who can do nothing still does nothing.

The caveat rides on every tool

Each description ends with the measurement caveat initialize hands back as instructions. A model handed a profiled-versus-duration ratio without it invents a cause for the gap, and the invented cause reads like a finding.
