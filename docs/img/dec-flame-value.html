A stat times the request; a flame value is a rendering artifact

Two numbers describe one request, from a real record: the record, the raised root and the child's 355 s offset are drawn to scale. duration_ms is what the request took, measured once. A flame node's value is a layout width, raised so a parent covers its positioned children.

Three places raise a value

Flame_Tree::cover_children(), Flame_Fold::flatten() and Flame_Builder_Node::fill().

Raising is right for drawing. The browser prunes on a single cutoff and takes a whole subtree with anything it drops, and treemapDice scales children by parentWidth / parent.value.

The rule

Every stat reads $request['duration_ms'], and nothing measured reads a flame value. That covers every namespace of decision 1 plus the per-URL aggregate's sum_value. Raising is wrong for counting.
