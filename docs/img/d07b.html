The live hub is four lines, and fifteen names a spoke

The top-level topology names ONE include, ELN's own hub composition, which runs both stock Vault_Group legs — each a make_node line building a child per Vault entry in group spoke — and each child still costs the hub the names below.

aggregator-hub.tsl · the whole top-level file
var on_demand_idle = 0
The worker never idles out, so the streams stay open.
var num_partitions = 1
One instance holds every spoke.
include hub
ELN's own composition of aggregator (firehose and PHP errors in) and hub-control (commands out) — both legs, below.
secure
Freezes the graph: no later command builds or removes a node. A Vault_Group still builds and retracts members on the fleet's Vault RELOAD after this — membership was declared before securing, and reload replays it rather than issuing a fresh make_node.
aggregator.tsl · the spokes Vault_Group leg, via include hub
make_node Vault_Group spokes Remote_Source spoke <config:offsets_dir>/<topology>.{id} <config:deadletter_dir>/<topology>.{id} firehose.p{partition}:remote-job-rewrite sources/php:php-errors:partition
One line, every spoke: a Remote_Source per id in group spoke, {id} substituted for each, holding ONE connection that carries the spoke's firehose and its PHP error log. Each pair names where its stream goes, and each stream's reader keeps its cursor under <topology>.{id}/, so two hubs stay off one offsetlog.
command_node spokes:config assume_clean_shutdown true
Recorded once, on the group. Replayed to every child, present now or built later, and fanned out to its readers: each record is durable in the hub's log before the worker stops, so a cooperative stop commits past the in-flight record instead of replaying it. Without it, every worker recycle delivers one record twice.
command_node spokes:config set_multi_writer true
Recorded once, on the group. Every request process on a spoke appends to its log, so a request can still be writing a segment after the next opens. The verb asks the spoke's reader to hold the old segment for a grace period.
make_node File_Tail php-errors:tail sources/php …
connect_node php-errors:tail php-errors:partition
The hub's own PHP error log joins every spoke's in php-errors.p0; each line's FROM opens with the reader or Tail that took it.
One line per leg; membership from Vault group spoke.
hub-control.tsl · the settings Vault_Group leg, via include hub
make_node Null null
Built once, ahead of the group: the shared sink every child's egress ends at.
make_node Vault_Group settings HTTP_Out spoke
The outbound leg, one HTTP_Out per id in group spoke, each reading that id's own Vault entry.
command_node settings:config allow_replies_to settings-sync
command_node settings:config allow_replies_to discovery-collector
The reply gate, recorded once on the group — not once per spoke. Replayed to every child. The list fails closed, so a missing declaration drops every spoke's acks silently, not just one's.
connect_node settings-sync settings
connect_node discovery-collector settings
Both minters fan out to the group by name. A Tee cannot do it: re-addressing a signed command after the mint makes it verify nowhere.
connect_node settings null
The group's own target: one shared Null catches whatever a spoke leaves unaddressed.
One line per leg; membership from Vault group spoke.

What one child, spokes:bend, costs: thirteen names

The group builds one Remote_Source per Vault entry named in group spoke — bend here. Each child builds the rest of this tree itself on its first tick, a reader per stream with its own cursor and quarantine, and each takes a name in the worker's registry.

spokes:bend · the broker
├─ spokes:bend:config · verbs
├─ spokes:bend:sse-in · the stream
├─ spokes:bend:http-out · commands
├─ spokes:bend:null · unaddressed
├─ spokes:bend:firehose.p0 · reader
│  ├─ :config · :offsetlog · :deadletter
└─ spokes:bend:sources:php · reader
   └─ :config · :offsetlog · :deadletter

The five in blue are hidden: the broker owns them and names them after itself; it rebuilds its transports when its credentials change.
